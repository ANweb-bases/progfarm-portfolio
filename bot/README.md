# ProgFarm bot — @ProgFarmBot
Заказ и оплата услуг, связь с владельцем. Запуск: `node bot.js` (Node 18+, зависимостей нет). Токен в `.env` (см. `.env.example`).

- Услуги и цены → «Заказать и оплатить» (оплата в боте подключается позже; заявка фиксируется).
- «Связаться со мной лично» — вопрос приходит владельцу, ответ реплаем уходит пользователю.
- Ссылки с сайта вида `t.me/ProgFarmBot?start=svc3` открывают сразу нужную услугу.
- Чтобы заявки и вопросы приходили вам: напишите боту `/myid`, вставьте число в `ADMIN_ID` в `.env`, перезапустите.
