# ProgFarm bot — @ProgFarmBot

Бот-витрина и приёмная студии: услуги, калькулятор, заявки со статусами, диалог с владельцем, отзывы.
Запуск: `node bot.js` (Node 18+, зависимостей нет). Токен и `ADMIN_ID` — в `.env` (см. `.env.example`).

## Для клиента
- 🛠 Услуги и цены: 11 услуг, карточки с составом и сроками.
- 🧮 Калькулятор: услуга → сложность → срочность → вилка цены.
- ⚡ Заявка за минуту: услуга, описание (текст, фото, файлы, голосовые), сроки, бюджет, проверка и отправка.
- 🧾 Мои заявки: статусы и история, уведомления при каждом изменении, оценка готовой работы.
- 💬 Связь с владельцем: пишете прямо в бот, ответ приходит в тот же чат.
- 📁 Портфолио, ❓ вопросы и ответы, 📞 контакты.

## Для владельца
- Каждая заявка приходит карточкой с кнопками статуса: принять, в работу, счёт, готово, отклонить. Клиент получает уведомление автоматически.
- Отвечать клиенту можно реплаем на любое сообщение по заявке или кнопкой «Написать клиенту» (режим диалога, `/cancel` выходит). Поддерживаются текст, фото, файлы и голосовые.
- `/admin` — панель: пользователи, заявки по статусам, средняя оценка, открытые заявки, рассылка.
- Ссылки с сайта: `t.me/ProgFarmBot?start=svc3` открывает услугу, `?start=order` — заявку, `?start=calc` — калькулятор.

Данные хранятся в `data/store.json` (в репозиторий не попадает). Чтобы подключить получение заявок, напишите боту `/myid` и вставьте число в `ADMIN_ID`.
