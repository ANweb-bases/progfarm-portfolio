# ProgFarm — портфолио

Сайты, приложения, Telegram-боты и базы данных на заказ. Цены от 1 500 ₽.

**Онлайн:** https://anweb-bases.github.io/progfarm-portfolio/

## Проекты

| Проект | Что делает |
|---|---|
| [ProgFarm](01-progfarm/progfarm.html) | Сайт-визитка: услуги с анимацией каждой услуги, проекты, установка приложений |
| [Счёт](02-schet/schet.html) | Генератор счетов с экспортом в PDF |
| [DevKit](03-devkit/devkit.html) | JSON, Base64, хеши, UUID, цвета, пароли, Unix-время |
| [ПроФинанс](04-profinance/profinance.html) | Калькуляторы кредита, вклада и накоплений |
| [HabitFlow](apps/habitflow) | Windows-приложение: трекер привычек |
| [ClipFlow](apps/clipflow) | Windows-приложение: история буфера обмена |
| [Копилка](apps/kopilka) | Windows-приложение: учёт доходов и расходов |
| [Night City Build Advisor](cyberpunk-builder) | Помощник по билдам Cyberpunk 2077 (сайт и .exe) |
| [bot](bot) | Telegram-бот ProgFarm (Node.js), временно недоступен |

Готовые `.exe` лежат в [Releases](../../releases/latest). Сборка из исходников: `apps/build.bat` (нужен только .NET Framework 4, он есть в Windows 10/11).
