Каркас бота для продаж

Нажимайте кнопки в телефоне слева — так будет вести себя бот. Структура уже готова, остаётся наполнить её вашими товарами и подключить оплату.

Что внутри каркаса

  • Приветствие и главное меню
  • Каталог с разделами и карточками товара
  • Корзина и оформление заказа
  • Раздел «Контакты» и обратная связь
  • Заготовка под оплату (подключается позже)

Так выглядит код (шаблон `bot-template.js`)

// каждый экран — это объект: текст + кнопки
const screens = {
  menu:    { text: 'Добро пожаловать!', kb: [['🛍 Каталог','catalog'],['🛒 Корзина','cart']] },
  catalog: { text: 'Выберите раздел',   kb: [['Букеты','cat1'],['Комнатные','cat2']] },
  pay:     { text: 'Оплата скоро!',     kb: [['⬅ Меню','menu']] }
};
